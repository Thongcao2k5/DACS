--- TECH STACK ---
- ASP.NET Core MVC 9.0
- Entity Framework Core 9.0
- SQL Server (MSI\SQLEXPRESS, Windows Auth, MotorcycleShopDB)
- ASP.NET Core Identity (cookie 7 ngày, lockout 5 lần sai)
- AutoMapper 14
- Serilog (rolling 7 ngày, Logs/log-.txt) — file sink v7
- SixLabors.ImageSharp
- ClosedXML (export Excel)
- VNPay (thanh toán online)
- MailKit 4.7.1 (thay thế System.Net.Mail) — Gmail SMTP qua App Password

--- KIẾN TRÚC 3-TIER ---
MotoShop            → Presentation (Controllers, Views, ViewComponents, wwwroot)
MotoShop.Business   → Business Logic (Services, DTOs, Interfaces, Mappings, Helpers)
MotoShop.Data       → Data (DbContext, Models, Repositories, Migrations)

Pattern: Repository + UnitOfWork, Dependency Injection, AutoMapper DTO mapping
Khi thêm feature mới: interface → service → đăng ký DI trong Program.cs

--- CÁC FILE QUAN TRỌNG ---
Program.cs              - DI, Identity, EF, middleware config + raw SQL schema trên startup
MotoShopModels.cs       - Tất cả entity models trong 1 file
MotoShopDbContext.cs    - EF context kế thừa IdentityDbContext
DbSeeder.cs             - Seed dữ liệu ban đầu

--- CÁC THAY ĐỔI CHI TIẾT (11/05/2026) ---

1. EMAIL (MailKit)
   - Chuyển EmailSender từ System.Net.Mail → MailKit.Net.Smtp
   - Hỗ trợ SecureSocketOptions.Auto (tự chọn StartTls/SSL)
   - Logging chi tiết khi connect, authenticate, gửi, lỗi auth
   - Gói: MotoShop.Business.csproj thêm MailKit 4.7.1

2. TÌM KIẾM TIẾNG VIỆT KHÔNG DẤU
   - ProductService.cs & ProductController.cs dùng EF.Functions.Collate("SQL_Latin1_General_CP1_CI_AI")
   - VietnameseStringHelper.NormalizeKeyword() chuẩn hóa từ khóa trước khi tìm
   - Áp dụng cho: ProductName, Description, BrandName, CategoryName
   - Autocomplete search cũng được cập nhật

3. UPLOAD FILE (FileService)
   - Validate MIME type (image/jpeg, image/png, image/webp) — bỏ gif
   - Validate file size tối đa 5MB
   - Magic bytes check nhất quán giữa SaveFileAsync và SaveImageAsync
   - Chuẩn hóa danh sách extension/MIME dùng chung

4. AUDIT LOG
   - Model: AuditLog entity (Id, UserId, Action, EntityName, EntityId, OldValues, NewValues, IpAddress, CreatedAt)
   - SQL: tạo bảng AuditLogs trong Program.cs startup
   - DbContext: thêm DbSet<AuditLog>
   - IAuditLogService đăng ký DI trong Program.cs
   - Admin/ProductController: log hành động "Delete" khi xóa mềm sản phẩm

5. REVIEW SẢN PHẨM CÓ ẢNH
   - Model: ProductReviewImage entity (Id, ReviewId, ImageUrl)
   - ProductReview: thêm navigation ICollection<ProductReviewImage> Images
   - SQL: tạo bảng ProductReviewImages trong Program.cs startup
   - DbContext: thêm DbSet<ProductReviewImage>
   - ProductReviewDto: thêm AvatarUrl, ReviewImages
   - MappingProfile: map AvatarUrl từ Customer.AvatarUrl, ReviewImages từ Images

6. MAPPING PROFILE CẬP NHẬT
   - ProductDto: thêm FlashSaleEndDate, StockCount, IsInStock
   - MappingProfile: map FlashSaleEndDate (ngày kết thúc flash sale đang active)
   - StockCount = tổng tồn kho các variant; IsInStock = có ít nhất 1 variant > 0

7. FLASH SALE ADMIN

   - FlashSale/Index.cshtml: 3 dashboard cards, DataTables integration (v1.13.4, i18n tiếng Việt)
